
# LE-Hud-Installer

Automated MelonLoader and [HUD Mod](https://github.com/Syncingoutt/LastEpoch_Mods) Installer 

## Installation

Download `Last Epoch HUD Installer.zip` in [Releases](https://github.com/TriSSec-Lab/LE-Hud-Installer/releases) and extract it into your root Last Epoch game folder. (where your Last Epoch.exe is located)

Run it once, Follow the instructions, It'll tell you to open Last Epoch once and then run `Last Epoch HUD Installer.bat` again.

## Update

To update the HUD mod simply launch `Last Epoch HUD Installer.bat` again.

If the game updated just launch Last Epoch.exe once and then run `Last Epoch HUD Installer.bat` again.

## Uninstall

Remove these files to fully uninstall the HUD and MelonLoader

* `MelonLoader/` (**Folder**)
* `UserData` (**Folder**)
* `Mods/` (**Folder**)
* `Plugins/` (**Folder**)
* `UserLibs/` (**Folder**)
* `version.dll`
* `Last Epoch HUD Installer.bat`
